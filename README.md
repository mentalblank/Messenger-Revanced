# Facebook Messenger - De-Vanced & Rushiranpise (Auto-Build)

Two patched builds of Messenger, one per patch source. Both are published in every release.

| APK | Patch source | Patches on by default | Built against |
| --- | --- | --- | --- |
| `messenger-devanced-…` | [De-Vanced](https://github.com/RookieEnough/De-Vanced) | 7 of 9 | 573.0.0.44.88 |
| `messenger-rushiranpise-…` | [morphe-patches](https://github.com/rushiranpise/morphe-patches) | 12 of 20 | 576.0.0.47.92 |

Each comes in `arm64-v8a` and `arm-v7a`. Pick the one matching your device.

## Installation

1. Install the latest version of [Build APK](https://github.com/MentalBlank/Messenger-Revanced/releases/latest).
2. Use [Obtainium](https://github.com/ImranR98/Obtainium) to download and install build updates.

The Rushiranpise build has **Change package name** enabled, so it installs alongside stock Messenger as a separate app rather than replacing it. The De-Vanced build does not, so it replaces stock Messenger and needs the stock app uninstalled first.

## Patches

**De-Vanced** — Hide inbox ads · Hide inbox stories and notes tray · Hide inbox subtabs · Disable typing indicator · Hide Facebook buttons · Open links externally · Remove Meta AI

Available but off by default: Change package name, Spoof package version.

**Rushiranpise** — everything above, plus: Enable chat heads · Disable media transcoding · Change package name · Allow screen capture · Block screenshot detection

Available but off by default: Spoof package version, Disable PairIP license check, Provide Original app certificate, Spoof Widevine / DRM level, Fix Firebase after re-signing, GmsCore support (MicroG), Spoof install source, Spoof app signature.

## Disclaimer

This patch modifies the original APK, and may violate the app provider's terms of service. Use at your own risk.
